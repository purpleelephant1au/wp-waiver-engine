# Guide Directory Structure

This folder uses a flow-based screenshot layout and consistent file prefixes.

## Guides

- simple-waiver-use-case.md: Template setup and field mapping walkthrough
- standard-form-user-flow-guide.md: Single signer form submission flow
- repeatable-form-user-flow-guide.md: Repeatable participants form submission flow

## Screenshot Folders

- screenshots/template-setup-flow: TFLOW-xx files
- screenshots/standard-form-flow: SFLOW-xx files
- screenshots/repeatable-form-flow: RFLOW-xx files

## Naming Convention

- Template setup sequence: TFLOW-01 ... TFLOW-14
- Standard form sequence: SFLOW-01 ... SFLOW-08
- Repeatable form sequence: RFLOW-01 ... RFLOW-08

## Rules for Future Captures

- Store every screenshot in the matching flow subfolder.
- Keep step numbers zero-padded (01, 02, 03).
- Keep markdown image links relative to this user-guides/simplewaiver folder.
- Avoid placing loose image files directly under screenshots.
